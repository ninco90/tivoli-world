# Cómo contribuir

1. Abre una incidencia que describa el cambio y enlace la foto, vídeo, plano o dato que lo respalda.
2. Crea una rama y realiza cambios pequeños y revisables.
3. Ejecuta `npm ci` y `npm run build` antes de enviar una pull request.
4. Distingue en el texto y la interfaz los datos medidos de las interpretaciones. No presentes una atracción como operativa ni una propuesta como proyecto aprobado si la fuente no lo demuestra.
5. No incluyas fotografías, renders, PDF ni otros materiales de terceros sin una licencia de redistribución comprobada. Puedes enlazar la fuente original.

En particular, el trazado y los pasos ocultos de Tívoli Agua siguen siendo aproximados. Una mejora debería documentar cómo conecta cada tramo visible antes de ajustar las alturas o la decoración.
